# Updating the website: staff guide

Go to **your-website.com/keystatic** and sign in with the email you were invited with.

On the left you'll see:

| Section | What it's for |
|---|---|
| **Café details** | Name, address, phone, WhatsApp ordering, Instagram, currency, colour theme |
| **Opening hours** | Hours for each day, a "Closed all day" box, and a note (e.g. "Closed 25 December") |
| **Drinks** | Every drink on the menu |
| **Bakery** | Cookies, muffins and anything else from the bakery, with prices and photos |
| **Coffees on bar** | The beans you're currently serving |
| **Homepage text** | The big headline, intro, scrolling banner and section titles |

**After any change, press the blue Save button (top right).** The live website updates about a minute later. Refresh the page to see it.

## Common jobs

**Change a price.** Drinks → click the drink → change *Price* → Save.

**Take a drink off the menu for a while.** Drinks → click it → untick *On the menu* → Save. Tick it again to bring it back. Nothing is lost.

**Add a new drink.** Drinks → *Add* (top right). Fill in the name, *Menu tab* (type an existing tab name like `Espresso bar` to put it there, or a new name to create a new tab), price and description. Under *3D cup appearance*, choose the cup, a colour and the surface. Save.

**Change the order of drinks.** Each drink has a *Sort order* number. Lower numbers appear first in their tab (we use 10, 20, 30… so there's room to slot new ones between).

**Holiday hours.** Opening hours → change the day, or tick *Closed all day*. Add a short note at the bottom so customers know it's temporary. Remember to change it back afterwards.

**Swap the coffee on bar.** Coffees on bar → untick *On bar now* for the old one, then *Add* the new one.

**Sold out of a cookie or muffin.** Bakery → click it → untick *Available today* → Save. Tick it again tomorrow.

**Add a photo to a bakery item.** Bakery → click it → *Photo* → upload a square photo → Save. It replaces the drawing.

**Add a new bakery item.** Bakery → *Add*. Type `Cookies` or `Muffins` in *Bakery tab* (or a new name, like `Cakes`, to create a new tab), add the price, tick any dietary tags. For the 3D model, pick the *Shape* (cookie or muffin), a *Colour* for the dough (copy one from a similar item) and the *Topping*. Save.

**Pause online orders** (e.g. a very busy morning). Café details → *Online ordering* → untick *Take pickup orders on the website* → Save. Tick it again when you're ready.

## Handling an order

Orders arrive as a WhatsApp message on the café's number, like this:

> New pickup order for Ember & Oak · Name: Priya · Pickup: Today at 10:30 · 2 × Flat White · 1 × Blueberry Muffin · Total: $12.75

1. Reply to confirm, e.g. "Thanks Priya, see you at 10:30!" (or suggest another time if you're swamped).
2. Make the order for the pickup time.
3. The customer pays at the counter when they collect.

## Tips

- Keep descriptions to one short sentence. They're shown on phones too.
- Times use the 24-hour clock: `07:00`, `18:30`.
- Drink colours are hex codes like `#A87148`. If unsure, copy one from a similar drink.
- If something looks wrong on the website, open the same item and use the clock icon (top right) to undo your changes before saving.
